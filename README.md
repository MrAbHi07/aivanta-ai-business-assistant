# Aivanta Admissions AI

Build the first Aivanta portfolio product: “Aivanta AI Business Assistant v0.1”, initially positioned as an AI Admission Assistant for coaching institutes/education businesses. This is a client-facing demo, not just a landing page. Create a polished, premium SaaS-style web app using the default stack. Brand: AIVANTA. Primary tagline: “AI Built for Business.” Positioning: “AI Automation & Solutions for Small Businesses.” The demo should show a realistic AI chat assistant that can answer course/fees/batch FAQs, collect a lead’s name/phone/course interest, qualify the lead, and offer human handoff. Include a professional public landing page with hero, problem/solution, demo preview, features, workflow, use cases, and CTA; plus the actual interactive assistant demo page. Use realistic sample coaching-institute data and clearly label demo/mock data where appropriate. Do not require paid APIs for the first version; make the chat work with a deterministic local/mock response engine and structure the code so a real LLM/API can be integrated later. Make the UI responsive, polished, accessible, and suitable for showing to a paying client. Include a simple lead capture flow and an admin/demo overview page showing captured leads with sample data. Do not add authentication or payments yet. Prioritize visual quality and a convincing end-to-end client demo.
